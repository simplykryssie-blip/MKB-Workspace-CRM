# MKB Financial Group website — HTML pages

The live pages are edited in the CRM (Website → each page's HTML). These files are
the starting versions (metallic gold foil design), kept here as a backup.

- `pages/` — one full HTML document per page (home.html is the home page).
- `media/` — the photos and logo uploaded to the Media library (`/site/media/<name>`).
- `build.py` — the script that generated the pages (shared styles, header, footer).

Gold system classes: `metallic-gold-text`, `metallic-gold-button`, `metallic-gold-divider`,
`metallic-gold-icon`, `metallic-gold-border` (tokens at the top of each page's `<style>`).
